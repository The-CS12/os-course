### 🧠 Processor (پردازنده):

کمتر کسی هست که اسم پردازنده به گوشش نخورده باشه. سخت‌افزاری که وظیفه پردازش دستورالعمل‌ها، کنترل مسیر اجرای برنامه‌ها و اعمال تغییرات روی دیتاها رو داره. تو اکثر مواقع، منظور از پردازنده صراحتاً **Central Processing Unit** یا **CPU** هستش. <br>

{{< readmore title="یکم بیشتر بدونید" open="false" >}}
کامپیوترهای امروزی با معماری `John von Neumann` (فون نویمان) ساخته می‌شن. این معماری پردازنده رو به سه بخش تقسیم می‌کنه: <br>

* ALU (Arithmetic Logic Unit)

> وظیفه این بخش انجام عملیات‌های محاسباتی یا منطقی هستش. (یه جورایی مغز پردازنده محسوب می‌شه.)

* CU (Control Unit)

> این بخش مثل اتاق فرمان می‌مونه و کنترل بخش‌های پردازنده بر عهده این واحد کنترل هستش.

* Registers

> رجیسترها حافظه‌هایی داخل CPU هستن که اطلاعات برنامه‌ها و دستورالعمل‌های در حال اجرا رو توی خودشون نگه می‌دارن.
> {{< /readmore >}}

### 💾 Main Memory (حافظه اصلی):

توی این حافظه، دیتای مربوط به برنامه‌ها و پردازه‌های در حال اجرا ذخیره می‌شه. حافظه اصلی **فرّار** هستش؛ یعنی بلافاصله بعد از قطع جریان برق (خاموش شدن سیستم)، دیتای داخلش از بین می‌ره. به حافظه اصلی `Real Memory` یا `Primary Memory` هم می‌گن. اصولاً از **RAM** به عنوان حافظه اصلی توی کامپیوترها استفاده می‌شه.

### ⌨️ I/O Modules (ماژول‌های ورودی و خروجی):

وظیفه این ماژول‌ها انتقال دیتا بین ماژول‌های (می‌تونید برای راحتی، ماژول‌ها رو دیوایس در نظر بگیرید.) داخلی و خارجی هستش؛ مثل سنسورها یا دیوایس‌های ذخیره‌سازی.

### 📬 System Bus (باس‌ها):

باس‌ها مسیرهایی برای جابه‌جایی و انتقال دیتا بین پردازنده، حافظه و ماژول‌های I/O هستن. باس‌ها مثل **پستچی**، دیتاها رو بین بخش‌های مختلف جابه‌جا می‌کنن.
